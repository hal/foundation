# halOS (HAL on OpenShift)

::: info Planned
halOS is not yet implemented. This page describes the planned vision and will be updated as the edition takes shape.
:::

halOS will integrate with the OpenShift console to manage WildFly instances running on OpenShift.

## Vision

- Integrate with the OpenShift console UI
- Manage WildFly instances deployed on OpenShift
- Leverage OpenShift APIs for discovery and lifecycle management

Watch the [GitHub issues](https://github.com/hal/foundation/issues) for progress updates.
