# HAL Foundation

HAL Foundation is the codebase for the next major version of the HAL management console for [WildFly](https://www.wildfly.org/) and JBoss EAP. It produces two editions:

- **halOP** (HAL On Premise) — successor to the current [HAL management console](https://github.com/hal/console), ships bundled with WildFly or runs as a standalone application
- **halOS** (HAL On OpenShift) — future edition for managing WildFly instances on OpenShift (not yet implemented)

## About This Documentation

This documentation covers the features, architecture, and planned work for both editions. It serves as the primary reference for roadmap planning.
